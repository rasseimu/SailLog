# GPS軌跡ビューア（モック）設計書

- 日付: 2026-08-14
- ステータス: 承認済み（実装計画待ち）
- 種別: 新規プロジェクト（sailing パイプラインとは独立したモックWebサイト）

## 1. 目的とスコープ

セーリング練習のGPSログ（Sensor Logger形式CSV）を、Webブラウザ上で
**選択・時間クロップ・時系列再生・複数軌跡/タグの重ね合わせ**して可視化する
モックサイトを作る。データベースやパイプラインとは分離した、完全クライアント側の
静的サイトとして新規gitリポジトリで管理する。

### 対象データ（実測）
`gps/` に3ファイル（実練習データ）:
- `Location0807.csv`（14,755行）, `Location0808.csv`（16,318行）, `Location0809.csv`（11,368行）
- Sensor Logger（iOS）形式。ヘッダー例:
  `time,seconds_elapsed,altitude,speedAccuracy,bearingAccuracy,latitude,altitudeAboveMeanSeaLevel,bearing,horizontalAccuracy,verticalAccuracy,longitude,speed`
- `time` はエポック**ナノ秒**（整数）。緯度経度は相模湾（lat≈35.30, lon≈139.48）付近。
- 注意: 先頭行の `seconds_elapsed` が負になる等、相対秒には基準ズレがある。**`time`(ns) を主時刻**として扱い昇順ソートする。
- `horizontalAccuracy` は点ごとに大きく変動（例 23〜265）。飛び値が混じる。

### スコープ内
- CSVのドラッグ&ドロップ／ファイル選択での読込（複数可）
- 軌跡の2Dプロット（実地図タイルなし・正距円筒投影）と pan/zoom
- 時系列再生（マーカーがトラック上を移動、play/pause、速度倍率、スクラブ）
- 時間クロップ（タイムライン両端ハンドルで表示・再生範囲を限定）
- 複数GPS軌跡の重ね合わせ（色分け・表示切替・凡例）
- タグ/イベントCSVの重ね合わせ（タイムライン＋任意でトラック上ピン）
- 整列モード（絶対時刻／経過時間）
- 外れ値（スパイク）除去（簡易・既定ON）
- 精度フィルタ（任意・既定OFF）

### スコープ外（YAGNI）
- 実地図タイル（OSM/海図）
- 速度・風などの時系列グラフ（下部グラフ）
- DB連携・認証・サーバーサイド処理
- モバイル最適化（デスクトップブラウザ前提）

## 2. 技術アプローチ

**ゼロビルド・バニラ + Canvas 2D**。npm もバンドラも使わない ES モジュール構成。
`python -m http.server` 等の静的配信で即動作し、オフライン共有が容易。
将来 TypeScript/Vite 化したくなった場合も移行は容易。

- 描画: Canvas 2D + `requestAnimationFrame`
- 状態管理: 単純な中央 state オブジェクト（app.js）
- 依存ライブラリ: なし（CSVパースも自前の軽量パーサ）

## 3. データモデル

### 3.1 GPS トラック
```
Track {
  id: string            // ファイル名由来
  name: string          // 表示名（編集不可でよい）
  color: string         // 自動割当（パレット循環）
  visible: boolean       // 表示切替
  points: Point[]        // time昇順
  bounds: {minLat,maxLat,minLon,maxLon}
  tRange: {start,end}    // ms
}
Point {
  t: number             // epoch ms（time(ns)/1e6）
  lat: number
  lon: number
  speed: number|null
  bearing: number|null
  accuracy: number|null // horizontalAccuracy
}
```
- パース: ヘッダー行から列インデックスを解決。必須列は `time, latitude, longitude`。
  欠けていればそのファイルは読込エラーとして通知。
- 数値化に失敗した行、緯度経度が NaN/範囲外の行はスキップ。
- `time` は ns整数（大きい整数）を ms(number) に変換。ISO文字列も受理（後述の共通時刻パーサ）。

#### 外れ値（スパイク）除去 — 既定ON
GPSの飛び値で軌跡が乱れるのを防ぐ簡易フィルタ。精度フィルタ（§下）とは独立。
- time昇順ソート後、隣接点間の**推定速度** `v = haversine距離(prev,cur) / Δt` を計算。
- `v` が閾値（既定 25 m/s ≒ 90 km/h、ディンギーの現実的上限を大きく超える値）を
  超える点を**外れ値としてスキップ**し、次点は直前の採用点を基準に再判定する
  （連続スパイクにも対応）。`Δt<=0` の重複時刻点も除去。
- 除去した点数を読込時に通知（例: 「12点を外れ値として除外」）。
- 閾値は定数で持ち、後から調整可能にする（UIトグルは今回不要）。

### 3.2 タグ/イベント
列構成で自動判別（ヘッダー小文字化して照合）:
- `start` と `end` を持つ → **区間イベント**（range）
- `time`（または `start` のみ）を持つ → **点イベント**（point）
- `label`（無ければ `name`/`text`）→ 表示名（任意）
- `lat`/`lon`（`latitude`/`longitude` も可）→ あればトラック上にピン配置。
  無ければ「基準トラック」の位置を時刻補間して配置（基準トラック＝最初に表示中のトラック）。

```
Event {
  kind: 'point'|'range'
  t: number             // point: 時刻ms / range: start ms
  tEnd: number|null      // range のみ
  label: string
  lat: number|null
  lon: number|null
}
```
- 時刻は ns整数／ISO文字列の共通パーサで ms に正規化。

### 3.3 共通時刻パーサ
入力（string|number）を epoch ms に変換:
- 数値かつ桁数が大きい（>1e15）→ ns とみなし /1e6
- 数値で ms 相当（~1e12）→ そのまま
- それ以外の文字列 → `Date.parse`（ISO想定）。失敗は NaN を返し呼び出し側でスキップ。

## 4. 座標変換・描画

### 4.1 投影（projection.js）
- 正距円筒。基準 `lat0,lon0` = 全表示トラックの外接矩形の中心。
- ローカル平面座標: `X=(lon−lon0)·cos(lat0·π/180)`, `Y=(lat−lat0)`。
- 外接矩形を Canvas にアスペクト比維持でフィット（余白 ~5%）、北を上（Y反転）。
- `fitBounds(tracks)` で初期ビューを算出。

### 4.2 ビューポート（viewport.js）
- スクリーン変換 = fit変換 × ユーザーの pan/zoom（scale, offset）。
- ドラッグでパン、ホイールでカーソル位置中心ズーム。
- `worldToScreen(pt)` / `screenToWorld(px)` を提供。

### 4.3 レンダラ（renderer.js）
- 毎フレーム: クリア → 各可視トラックのポリライン（クロップ範囲内の点のみ）→
  各トラックの再生マーカー（現在仮想時刻での補間位置、進行方向の向き表示は任意）→
  タグピン（lat/lon or 補間）。
- パフォーマンス: 14k点×数トラックは Canvas 2D で軽量。ズームアウト時は
  隣接点の画面距離が閾値未満なら間引く簡易デシメーション（任意・後回し可）。

## 5. 時間軸・再生

### 5.1 グローバル時間軸
- 整列モード=**絶対時刻**: 各点の `t` をそのまま使用。グローバル範囲＝全可視トラックの
  min(start)..max(end)。
- 整列モード=**経過時間**: 各トラックを自身の `tRange.start` を0として再マップ。
  グローバル範囲＝0..max(各トラック長)。
- 現在の仮想時刻 `now` はこのグローバル範囲内の値。

### 5.2 再生（playback.js）
- `requestAnimationFrame` で実経過 `dt` を取得し `now += dt·speed`。
- `now` がクロップ範囲末尾に達したら停止（またはループはしない＝停止）。
- API: `play()/pause()/seek(t)/setSpeed(x)`。速度倍率 = 1/2/4/8x。
- 各トラックのマーカー位置 = そのトラックの点列を `now` で二分探索＋線形補間。
  トラックの時間範囲外なら非表示。

### 5.3 クロップ（timeline.js）
- タイムライン両端に `[tStart,tEnd]` ハンドル。描画（ポリライン）・再生とも
  この範囲に限定。`now` は常に `[tStart,tEnd]` にクランプ。
- playhead ドラッグでスクラブ（= `seek`）。
- タグ点/区間をタイムライン上に描画（▲＝point、帯＝range）。ホバーで label。
- 時刻表示は `HH:MM:SS`（絶対）または `+MM:SS`（経過）。

## 8. テスト戦略

- **単体（`node --test`）**: DOM非依存の純粋関数を対象。
  - 共通時刻パーサ（ns/ms/ISO/不正値）
  - CSV種別自動判別（GPS vs タグ range/point）
  - GPSパース（必須列欠落・NaN行スキップ・time昇順ソート）
  - 外れ値除去（推定速度が閾値超の点をスキップ・連続スパイク・Δt<=0重複時刻）
  - 投影 `fitBounds` とアスペクト比維持
  - 位置補間（二分探索＋線形補間、範囲外null）
  - クロップ範囲クランプ、経過時間リマップ
  - これらは `src/` から DOM を import せず単体で呼べるよう設計する。
- **手動確認**: 実CSV3本で 読込→再生→クロップ→複数重ね→タグ重ね を一巡。
  ブラウザは静的配信（`python -m http.server`）で確認。

## 9. 受け入れ基準

1. `gps/` の3CSVをD&Dで読み込み、軌跡が正しいアスペクト比でプロットされる。
2. 再生ボタンでマーカーが軌跡上を時系列に移動し、速度倍率とスクラブが効く。
3. タイムライン両端で時間クロップでき、表示・再生がその範囲に限定される。
4. 複数トラックを色分けで重ね、表示切替できる。整列モード切替が反映される。
5. タグCSV（point/range）をタイムラインに重ね、任意でトラック上ピンが出る。
6. pan/zoom が滑らかに動作する。
7. 単体テストが全て通る。

## 10. リスクと対応
- 飛び値（低精度点）で軌跡が乱れる → 外れ値除去（既定ON）＋精度フィルタ（任意）＋NaN/範囲外スキップで緩和。
- 複数トラックの時刻基準ズレ → 整列モード（絶対/経過）で吸収。
- 大量点の描画負荷 → まず素直に全描画。必要なら簡易デシメーション（後回し可）。
